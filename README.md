## 📖 About

This repository is a comprehensive collection of Python programs covering core programming concepts, data structures, OOP, GUI development with Tkinter, file handling, and much more. It serves as a personal learning playground and a structured reference for Python fundamentals.

## ⚡ Getting Started

### Prerequisites

Make sure you have Python 3.x installed on your system.

```bash
# Check your Python version
python --version
```

### Running a Script

Clone the repository and run any script directly:

```bash
# Clone the repo
git clone https://github.com/aryankawale163/PYTHON.git
cd PYTHON

# Run any script
python calculator.py
python fibo.py
python functions/areaAndCircumference.py
```

### Running GUI Applications

Some scripts use **Tkinter** for graphical interfaces. Tkinter comes pre-installed with Python.

```bash
# Launch the GUI Calculator
python calculator.py

# Launch the Tkinter Login Form
python geometry.py
```

## 🌟 Featured Scripts

### 🖩 GUI Calculator — `calculator.py`
A functional desktop calculator built with **Tkinter** that evaluates mathematical expressions in real time.

```python
import tkinter as tk

def solve():
    result_label.config(text="Answer: " + str(eval(box.get())))

app = tk.Tk()
# ... full GUI setup
app.mainloop()
```

### 📐 Circle Calculator — `functions/areaAndCircumference.py`
Calculates the **area** and **circumference** of a circle using Python's `math` module.

```python
import math

def circle_state(radius):
    area = math.pi * radius ** 2
    circumference = 2 * math.pi * radius
    return area, circumference
```

### 🌀 Fibonacci Sequence — `fibo.py`
Generates the Fibonacci series — a classic algorithm for understanding recursion and iteration.

### 🌲 Tree Traversal — `tree/treeTraversal.py`
Implements **binary tree traversal** (in-order, pre-order, post-order).
